# whisp

**Русский** · [English](README.en.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform: macOS](https://img.shields.io/badge/Platform-macOS-lightgrey.svg)](#требования)

Одна команда превращает запись встречи в текстовый транскрипт с разделением по
спикерам. Транскрибация целиком выполняется на вашем Mac — аудио и видео никуда
не загружаются.

```bash
whisp "Запись встречи.m4a"
```

## Зачем это

Записи созвонов копятся, а слушать их заново никто не будет. Готовые онлайн-сервисы
расшифровки требуют залить туда файл целиком — что не всегда приемлемо для рабочих
встреч с клиентами и внутренних обсуждений.

`whisp` — тонкая обёртка вокруг [WhisperX](https://github.com/m-bain/whisperX),
которая закрывает этот сценарий локально:

- **Транскрибация** аудио и видео (`.mp3`, `.m4a`, `.wav`, `.mp4`, `.webm`, `.mov` и др.).
- **Диаризация** — реплики размечены по говорящим (`SPEAKER_00`, `SPEAKER_01`, …).
- **Работа из любой папки** — `whisp` доступен как обычная команда в терминале.
- **Опциональное саммари** (`-sum`) — темы, решения и задачи по итогам встречи.
- **Полная автоматизация для macOS** — положили файл в папку, забрали транскрипт.

Результат — файл `<имя-записи>.txt` рядом с исходником:

```
[SPEAKER_00]: Соберите все рабочие процессы в одном месте.
[SPEAKER_00]: От базовых рабочих сценариев до комплексного управления компанией.
[SPEAKER_01]: Свяжите стратегические цели с ежедневной работой команд.
```

## Требования

| Компонент | Зачем | Обязателен |
|---|---|---|
| macOS | Проект рассчитан на macOS (Apple Silicon) | да |
| [Homebrew](https://brew.sh) | Установка `ffmpeg` | да |
| `ffmpeg` | Декодирование аудио и видео | да |
| Python 3.11+ | Виртуальное окружение с WhisperX | да |
| Аккаунт [Hugging Face](https://huggingface.co) | Токен для модели диаризации | да |
| [Claude CLI](https://claude.com/claude-code) | Только для флага `-sum` | нет |

Понадобится около **5 ГБ** свободного места: сам PyTorch занимает большую часть,
плюс модели Whisper и диаризации скачиваются при первом запуске.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/saktush/whisp.git ~/whisp
cd ~/whisp
```

### 2. Установить ffmpeg

```bash
brew install ffmpeg
```

### 3. Создать окружение и поставить зависимости

```bash
python3 -m venv .venv
./.venv/bin/pip install -e .
```

Первая установка тянет PyTorch и занимает несколько минут.

### 4. Получить токен Hugging Face

1. Создайте токен с правами на чтение: https://huggingface.co/settings/tokens
2. Под тем же аккаунтом примите условия использования gated-модели диаризации —
   **без этого шага диаризация работать не будет**:
   https://huggingface.co/pyannote/speaker-diarization-community-1

### 5. Записать токен в `.env`

```bash
echo "HF_TOKEN=hf_ваш_токен" > .env
```

Файл `.env` добавлен в `.gitignore` и не попадёт в репозиторий.

### 6. Сделать `whisp` глобальной командой

```bash
echo "alias whisp='$HOME/whisp/whisp.sh'" >> ~/.zshrc
source ~/.zshrc
```

После этого `whisp` работает из любой директории.

## Использование

### Вручную

```bash
whisp <файл> [-sum]
```

- Транскрипт сохраняется как `<файл>.txt` **рядом с исходником**, а не в папке проекта.
- С флагом `-sum` дополнительно создаётся `<файл>-summary.txt` со структурированным
  саммари на русском: основные темы, решения, задачи.
- По завершении играет системный звук.

Саммари намеренно сделано необязательным этапом: если генерация упала или не уложилась
в 5 минут, вы получите предупреждение, но **транскрипт от этого не пострадает**.

Примеры:

```bash
whisp ~/Downloads/"Созвон с командой.m4a"          # только транскрипт
whisp ~/Downloads/"Созвон с командой.m4a" -sum     # транскрипт + саммари
```

### Автоматически: транскрибация при добавлении файла

macOS Folder Action следит за папкой проекта и сам транскрибирует (и суммирует)
любой аудио- или видеофайл, который туда попал.

Установка:

```bash
./automation/install-folder-action.sh
```

macOS один раз спросит разрешение на управление System Events — его нужно выдать.

Дальше достаточно перетащить файл в папку `~/whisp`:

- посторонние типы файлов игнорируются;
- скрипт ждёт, пока файл допишется до конца, — недокачанный файл в обработку не уйдёт;
- одновременно выполняется **не более одной** транскрибации, даже если файлов положили
  сразу несколько; остальные ждут своей очереди;
- по завершении приходит системное уведомление;
- лог пишется в `automation/whisp-automation.log`.

Отключить:

```bash
./automation/uninstall-folder-action.sh
```

Если вы правили `automation/whisp-folder-action.applescript`, перезапустите скрипт
установки — он перекомпилирует и переустановит Folder Action.

## Настройка

Переменные окружения (можно дописать прямо в `.env`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `HF_TOKEN` | — | Токен Hugging Face. Обязателен |
| `WHISP_LANG` | `ru` | Код языка записи (`en`, `de`, …) |
| `WHISP_MODEL` | `turbo` | Модель Whisper (`tiny`, `base`, `small`, `medium`, `large-v3`, `turbo`) |
| `WHISP_COMPUTE_TYPE` | `int8` | Тип вычислений CTranslate2 (`int8`, `float32`) |

```bash
WHISP_LANG=en whisp interview.mp3
```

## Приватность

- **Транскрибация и диаризация выполняются локально.** Аудио и видео не покидают вашу машину.
- **Исключение — флаг `-sum`.** Он передаёт текст готового транскрипта в Anthropic API
  через `claude` CLI. Если содержимое встречи не должно уходить наружу — не используйте
  `-sum`; на транскрибацию это никак не влияет.
- Сеть при первом запуске нужна для скачивания моделей с Hugging Face; дальше
  транскрибация работает офлайн.
- `.gitignore` намеренно исключает **все** медиафайлы и `*.txt`, чтобы записи и транскрипты
  не попали в git по неосторожности.

## Ограничения

- **Только CPU на Apple Silicon.** Движок CTranslate2 не поддерживает Metal/GPU, поэтому
  ускорения от видеокарты Mac не будет. Это всё равно заметно быстрее обычного
  `openai-whisper` и вдобавок даёт выравнивание по словам и диаризацию.
- **Саммари всегда на русском** — промпт зафиксирован в `whisp.sh`; смена `WHISP_LANG`
  влияет на транскрипт, но не на язык саммари.
- **Диаризация требует принятия условий** gated-модели pyannote (шаг 4 установки).
  Без этого WhisperX завершится ошибкой доступа к модели.
- Проект завязан на macOS: Folder Action, `osascript`-уведомления, `afplay` и `shlock`.
